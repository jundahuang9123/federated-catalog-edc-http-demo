# HTTP adapter examples

Use the maintained RDF snapshots in the repository-level `demo-data/` directory with `scripts/edc_http_simulator.py`.

The simulator represents the final `POST /catalog` action an EDC-side adapter could perform. This directory does not contain Eclipse EDC assets, DSP messages, contract agreements, policies, control-plane configuration or data-plane configuration.

See `docs/HTTP_INGESTION_CONTRACT.md` for the complete request contract and `docs/LIVE_DEMO.md` for the two-participant scenario.
