01 / OWNERSHIP

Your token identifies you.

The catalog decides which snapshot you can replace. A publisher cannot choose someone else’s graph.

02 / REPLACEMENT

One current catalog.

A successful push replaces your entire old catalog. Omitted datasets disappear from your contribution.

03 / DISCOVERY

Sources stay visible.

Search and query can span all catalogs. Shared identifiers connect resources without erasing their provenance.

Only metadata is pushed. The referenced data files stay with their providers. This demo does not run Eclipse EDC, DSP negotiation or an AAS server. The controls above simulate the workflow locally and send no network requests.

This is a synthetic discovery example, not the group’s earlier DPP data and not a validated DPP. The repository includes RDF metadata fixtures and a query; it does not include real AAS payloads or a live submodel service. Asset and shell identity mappings must be checked against the original AAS export before real data is substituted.
